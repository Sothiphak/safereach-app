Introduction

Project Overview

SafeReach is designed to solve real-world personal security and emergency delays. It functions as a resilient mobile panic button and responsive resource directory.

By combining geolocation tracking, category-based service lookups (Hospitals, Police, Fire, Ambulance), and local contact emergency channels, SafeReach acts as an all-in-one personal safety shield.

Purpose & Objectives

  • Minimize Response Time: Allow one-tap SOS trigger directly from the home screen.
  • Resilient Operations: Implement robust offline-first fallback capabilities for remote data.
  • Interactive Discovery: Leverage dynamic mapping and geo-filtering to guide users directly to closest services.

Challenge 1: Address Geocoding

Dynamic Address Resolution

Converting raw coordinates into human-readable locations dynamically via Nominatim Reverse Geocoding API.

Using http client requests with custom User-Agent parameters as required by OpenStreetMap policy, parsing city, suburb, or fallback formatting. 


// LocationState reverse geocoding
final url = Uri.parse(
  'https://nominatim.openstreetmap.org/reverse?format=jsonv2&lat=${position.latitude}&lon=${position.longitude}',
);
final response = await http.get(
  url,
  headers: {'User-Agent': 'SafeReachEmergencyApp/1.0'},
);
if (response.statusCode == 200) {
  final data = json.decode(response.body);
  final address = data['address'];
  final city = address['city'] ?? address['town'] ?? '';
  final suburb = address['suburb'] ?? address['road'] ?? '';
  _currentAddress = '$city, $suburb';
}

Challenge 3: Offline Resiliency

API Cache with Local Fallback

In safety applications, offline resilience is crucial. SafeReach guarantees functionality even without active internet:

  1. Try hitting NestJS server endpoint.
  2. Save successful response to SharedPreferences local cache.
  3. Fallback to local cache if network times out.
  4. Default to static JSON seeds included in assets if cache is empty.

// MockRepository fallback pattern
try {
  final apiItems = await _loadApiList(apiPath, fromJson);
  if (apiItems.isNotEmpty) return apiItems;
} catch (error) {
  debugPrint('API unavailable; using fallback.');
}

// Fallback 1: Local Cache
final cached = await _readCache(cacheKey);
if (cached != null) return _parseList(cached, fromJson);

// Fallback 2: Static JSON Assets
return _loadAssetList(assetPath, fromJson);

Challenge 4: Contacts Persistence


// ContactsState serialization
Future<void> load() async {
  _prefs = await SharedPreferences.getInstance();
  final stored = _prefs.getString(_contactsKey);
  if (stored != null) {
    final decoded = jsonDecode(stored) as List;
    _contacts.addAll(
      decoded.map((item) => PersonalContact.fromJson(item)),
    );
  } else {
    _contacts.addAll(_seedContacts());
  }
}

Future<void> _persist() async {
  final encoded = jsonEncode(_contacts.map((c) => c.toJson()).toList());
  await _prefs.setString(_contactsKey, encoded);
}

Dynamic JSON Persistence

Safeguards customizable details (e.g. emergency phone numbers, labels like Family or Neighbor).

Serializes models to JSON lists, writing dynamically to local SharedPreferences blocks whenever contacts are added, modified, or deleted.
